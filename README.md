# 📌 万能窗口置顶工具 (Topmost-Moyu-Tool)

这是一个基于 Python 开发的 Windows 窗口强制置顶工具，支持指哪打哪、暗黑风格界面以及后台托盘运行。

## ✨ 功能特性

- **🎯 指哪打哪**：鼠标移动到哪个窗口，点击即可强制置顶。
- **🛡️ 底层强制**：调用 Windows 底层 API，无惧普通窗口遮挡。
- **🖥️ 现代化 UI**：基于 `customtkinter` 构建的暗黑风格界面。
- **📥 托盘运行**：点击 X 不退出，自动缩到右下角托盘，随时一键解锁。
